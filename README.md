# Peri Bale

Bale akademisi tanıtımı için HTML, CSS ve JavaScript dosyalarından oluşan web sitesi.

## Sayfalar

- `index.html`: ana sayfa.
- `hakkimizda.html`: hakkımızda.
- `kurslar.html`: kurslar.
- `iletisim.html`: iletişim sayfası.

## Bilgisayarda açma

1. GitHub'da **Code → Download ZIP** seç.
2. İndirilen ZIP dosyasını çıkart.
3. `index.html` dosyasını tarayıcıda aç.
4. Menü bağlantılarını kontrol et.

## Dosya düzeni

`style.css` stilleri, `app.js` JavaScript kodunu ve `logo.jpg` logoyu içerir. `my-little-pony/` klasörü yazı tipi dosyalarını ve lisans metinlerini içerir; CSS bu klasördeki `pony.ttf` dosyasına başvurur.

## Sonraki adımlar

- Telefon ekranları için viewport ve uyumlu yerleşim eklemek.
- CSS içindeki Google Fonts import sırasını düzeltmek.
- Gerçek ekran görüntüsü eklemek.
- İletişim formunun davranışını ayrıca doğrulayıp belgelemek.

## Yazı tipleri

Yazı tiplerinin kullanım koşulları için `my-little-pony/` içindeki lisans metinlerine bak.
